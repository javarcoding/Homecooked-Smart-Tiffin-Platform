\# Homecooked – Smart Tiffin Service Platform



A full-stack role-based food delivery platform.



\## Tech Stack

\- Frontend: React (Vite), Tailwind CSS, Redux Toolkit

\- Backend: ASP.NET Core Web API, Entity Framework Core

\- Database: SQL Server

\- Auth: JWT



\## Roles

\- Customer

\- Chef

\- Delivery Partner

\- Admin
